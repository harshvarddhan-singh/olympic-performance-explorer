# Exercise Instructions

1. Use the attached Excel dataset to design and build a **web application** that provides a useful and intuitive way for users to explore and interact with the data.
2. Develop the application using **React and TypeScript**. You may use AI-assisted development or “vibe coding”, but you should understand the solution and be able to explain the code, technologies and decisions behind it.
3. The application should:
   - Address a meaningful user need rather than simply display the raw data.
   - Present insights, patterns or comparisons clearly.
   - Allow users to add or edit relevant data.
   - Be intuitive and accessible to a non-technical user.
   - Follow good software development and user-interface design practices.
4. You are free to transform the data, derive additional measures, use supporting libraries or introduce other features where they improve the usefulness of the solution.
5. Finally, create a concise **Power BI dashboard** using the same dataset. The dashboard should communicate the most important message or insight clearly, rather than simply presenting a collection of charts.
6. Be prepared to demonstrate your solution and discuss:
   - Your approach and key design decisions.
   - How you used AI during development.
   - Your understanding of the application and its code.
   - How you checked that the solution works as intended.
   - Any limitations and potential improvements.

During the interview, you will be asked to make live changes to both the web application and the Power BI dashboard. You should therefore understand your solution and be comfortable modifying it. A good working knowledge of React, TypeScript, HTML, CSS and DAX is important. You may use AI tools to support you, but you should be able to explain, validate and adapt the resulting work yourself.
